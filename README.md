# Metana Technical Evaluation - Frontend

This is the **Next.js frontend** for the Metana technical evaluation project.  
The app is built using **Next.js 15**, **TypeScript**, and **Tailwind CSS**, and it features optimized static pages and client rendering best practices.

## Features

- Fully built with **Next.js App Router**
- Static and dynamic routing
- UI using **Tailwind CSS**
- Client-side hydration with React
- Supports **dark/light theme** modes

## 🛠 Tech Stack

- **Framework:** Next.js 15
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** lucide-react
